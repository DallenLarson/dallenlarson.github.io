The problem

Tournament results become more useful when players can compare decks, matchup information, and trends in one place. DECKRISE is a product built around that workflow, covering Pokémon TCG and MARVEL SNAP analysis.

My contribution

I own product definition, interface development, data workflows, deployment, and ongoing iteration. ChatGPT and Claude are part of my development workflow. That describes how I build the product; it does not imply that its analysis is powered by an LLM.

What the public code demonstrates

The public JavaScript implementation includes sortable deck statistics, deck detail pages, card-price API lookups, browser-local price caching, and custom-deck persistence with localStorage. The README maps these responsibilities to individual source files.

A clear review boundary

The public repository is a source snapshot and may differ from the live product. Reviewers should use it to assess the documented implementation, not assume it contains every current production feature. The local preview also does not emulate Netlify functions.

A related data experiment

I also wrote about simulating Pokémon World Championships from tournament matchup data. The article explains the experiment and findings. Publishing the reproducible model and a fuller evaluation would be a useful next step; it is not presented here as a validated predictive system.
