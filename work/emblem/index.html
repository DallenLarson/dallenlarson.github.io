Emblem Forge

The design

Emblem Forge separates the responsibilities of a tactical game into a game manager, units, tiles, and a grid manager. The goal is to provide a foundation that another developer can adapt.

System responsibilities

The game manager coordinates turn flow and win/loss conditions. Units handle movement, attacks, and health. Tiles track terrain and occupancy, while the grid manager creates and populates the map.

How to review it

The README describes attaching the scripts to Unity objects and configuring their responsibilities. The repository provides source under the MIT license. Its release is labeled pre-release; it is a framework starting point rather than a finished commercial game.
